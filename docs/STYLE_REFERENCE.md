# Visual Reference Notes

The supplied screenshots show a consistent Discord presentation style:

- dark Discord background with a strong blue accent
- large banner/header image at the top
- concise title and subtitle
- thin separators and grouped information blocks
- dropdown menus for navigation
- private/ephemeral detail views for rules and support selections
- confirmation modals for ticket intake
- compact action buttons for staff/ticket workflows
- consistent footer branding

This repository translates that into conventional Discord embeds/components so it stays compatible with discord.js and persists cleanly after restarts. Configure Wisconsin State Roleplay logo/banner URLs through `/setup`.
